# Word Agent 智能批改系统

## 项目简介

基于大语言模型（DeepSeek）的新闻传播学考研作业自动批改系统，覆盖评论、消息、采访、策划四类作业，实现从"读取作业 → 智能批改 → 注入批注 → 生成总评"的全流程自动化。

## 核心职责

- **架构设计**：采用"LLM 清洗提取答案正文 → 全局诊断（结构化 JSON）→ 同窗口逐句批注 + 总评"的三阶段流水线，解决单次调用批改质量不稳定、总评缺失等问题。
- **文档批改**：基于 python-docx 操作 Word 底层 XML，实现绿色下划线肯定、黄色高亮纠错、删除线、段落级评语、表格单元格原生批注、总评追加等批改标记。
- **质量保障**：设计严格度校准 prompt（考研阅卷标准）、红绿隔离、逐句平衡批改等规则；实现 JSON 截断自动修复与重试机制，提升批改稳定性。
- **工程化**：支持一稿/二稿批改、按日期自动归档、参考答案 PDF 匹配、临时文件自动清理；通过 Git 管理版本迭代。

## 技术栈

Python、DeepSeek API、python-docx、pypdf、OpenAI SDK

## 成果

将原本需人工逐份批改的作业流程自动化，单份作业一次运行即可完成全文批注与评分，显著提升批改效率与一致性。经老师检验后，提升90%+工作效率。
